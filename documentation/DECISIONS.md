# РЕШЕНИЯ ЗАКАЗЧИКА И ПРИНЯТЫЕ ДОПУЩЕНИЯ

Решения пользователя (после Этапа 0):
1. **Классы опасности** в игре «Выбери бак» пользователю не показываются. В базе и коде хранятся (для будущего режима «Класс опасности»).
2. **Недочёты ТЗ** (REQUIREMENTS п.5) принимаются как есть. Значения «по умолчанию» из REQUIREMENTS считаются утверждёнными: несколько допустимых баков = засчитывать любой; спорные записи пометить `needs_review`, но использовать; запись без названия и класса в игру не включать.
3. **Настраиваемый уровень**: пользователь сам задаёт число отходов за раунд, время, порядок, число попыток, звук. Реализовано в `Settings` + экран «Настройка уровня» (Этап 1). Игра (Этапы 2–3) обязана читать эти значения.

Параметры уровня (`data/config.json` → `game_defaults`, ключи в `Settings`):
| Ключ | Значения | По умолчанию |
|------|----------|--------------|
| items_per_round | 3,5,10,15,20,30,50, 0=все | 10 |
| time_enabled | вкл/выкл | вкл |
| seconds_per_item | 3…60 | 15 |
| order | random / sequential | random |
| max_attempts | 0=без лимита, 1,2,3,5 | 0 |
| sound_enabled | вкл/выкл | вкл |

Пресеты (лёгкий / обычный / сложный) лежат в `data/config.json`, меняются без правки кода.
