# Сортируем вместе — проект Godot 4.7.2 (Android, вертикальная ориентация)

Развивающая игра для детей. Сейчас готов уровень **«Выбери бак»**; остальные четыре пункта меню
(«Класс опасности отходов», «Это что-то из чего-то», «Как подготовить отходы», «Путь отходов»)
выключены и помечены плашкой «Скоро».

> ⚠️ Проект написан без возможности запустить Godot (в среде сборки его нет). Статическая проверка
> (`python3 tools/check_project.py`) пройдена, но первый запуск в редакторе могут показать мелкие
> ошибки — пришлите текст из панели «Вывод/Отладчик», поправлю.

## Быстрый старт
1. Установите **Godot 4.7.2** (стандартная версия, не .NET).
2. `Проект → Импортировать` → выберите `project.godot`. Дождитесь импорта картинок (1–2 минуты).
3. F5 — запуск на ПК (окно 540×960). Мышь эмулирует палец: тяните картинку мышью.

## Сборка APK
1. `Редактор → Управление шаблонами экспорта` → скачать шаблоны 4.7.2.
2. Установите JDK 17 и Android SDK (cmdline-tools, platform-tools, build-tools, platform) —
   по инструкции Godot: https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_android.html
   Пути укажите в `Редактор → Параметры редактора → Экспорт → Android`.
3. Отладочный ключ, если Godot его не создал сам:
   `keytool -keyalg RSA -genkeypair -alias androiddebugkey -keypass android -keystore debug.keystore -storepass android -dname "CN=Android Debug,O=Android,C=US" -validity 9999 -deststoretype pkcs12`
   и укажите файл в тех же настройках (логин `androiddebugkey`, пароль `android`).
4. `Проект → Экспорт…` → пресет «Android (APK)» → «Экспортировать проект». Для Google Play
   нужен AAB: включите «Use Gradle Build», установите Android Build Template и release-ключ.
5. Имя пакета меняется в пресете (`package/unique_name`, сейчас `ru.sortiruem.vmeste`).

## Как играть / что умеет
* **Выбери бак**: вводный экран (нажми на бак — что в него можно выбросить, настройка уровня:
  «Отходов за раунд» и «Секунд на отход») → игра: картинку отхода **тянут пальцем и отпускают в бак**;
  отпустили мимо — картинка возвращается. Верно/неверно подсвечивается, ошибки показываются в итогах.
  Классы опасности в игре не показываются.
* **Редактор отходов** (главное меню): поиск, фильтры по классу и баку, создание / правка / удаление
  записей, выбор картинки из галереи, «Вернуть исходную таблицу». Данные хранятся в `user://waste.json`.
  В игру попадают записи с названием, картинкой и хотя бы одним баком.
* Кнопка «Назад» Android работает на всех экранах.

## Структура (модульность)
| Папка | Назначение |
|---|---|
| `design/` | **Весь дизайн**: `design_tokens.gd` (цвета, шрифты, размеры, скины-картинки), `tokens.tres` (ваши значения), `theme_builder.gd` (стили кнопок/панелей/надписей) |
| `core/` | Автозагрузки: `Router` (экраны), `WasteDB` (таблица + CRUD), `BinDB`, `GameRegistry`, `Store` (настройки, рекорды), `Sfx`, `ImageStore`, `Design` |
| `ui/` | Базовый экран и переиспользуемые компоненты (шапка, диалог, таймер, бак-мишень, перетаскиваемая картинка…) |
| `screens/` | Экраны: каждый — `.tscn` + `.gd` |
| `games/` | Чистая логика игр (без интерфейса) |
| `data/` | `waste_default.json` (исходная таблица), `bins.json` (баки и тексты), `games.json` (пункты меню) |
| `tools/` | Скрипты (импорт из docx, генерация иконок/звуков, проверка проекта) — в APK не попадают |

## Как поменять дизайн
* Цвета, шрифты, размеры, скругления: откройте `design/tokens.tres` → Инспектор.
* Свои картинки вместо заливки: поля `Tex Background / Tex Button / Tex Card` (9-patch).
* Свой шрифт: положите в `assets/fonts/`, укажите в `Font Regular / Font Bold`.
* Вид отдельных элементов (кнопки, карточки, чипы): `design/theme_builder.gd` — экраны ссылаются на
  варианты темы по имени (`SecondaryButton`, `CardPanel`…), поэтому правка в одном месте меняет всё.
* Раскладку экрана меняйте прямо в его `.tscn` в редакторе Godot.
* Тексты баков — `data/bins.json`; подпись плашки «Скоро» — поле `badge` в `data/games.json`.
* Звуки — замените файлы в `assets/sfx/` (те же имена). Иконка — `icon.svg` и `assets/android/`.

## Как добавить новый уровень
1. Сделайте экран в `screens/<имя>/` (унаследуйте `BaseScreen`), добавьте id в `Router.SCREENS`.
2. В `data/games.json` у нужной игры поставьте `"enabled": true` и `"screen": "<id>"`.

## Данные из ТЗ
84 отхода с картинками импортированы из docx (`tools/import_docx.py`). Таблица «Не надо» (8 записей
без картинок) не импортирована. В исходных данных есть противоречия (один отход — разные баки):
«Изделия из полиэтилена незагрязнённые», «Светодиодные лампы», «Бой керамики» — такие записи
помечены заметкой «Проверить» в редакторе. «Обувь кожаная рабочая» («Синий бак или…» обрезано) принята
как «синий бак или соцпроект». Мелкие опечатки в названиях исправлены.

## Известные ограничения
* Выбор картинки использует системное окно (`FileDialog.use_native_dialog`). Если на конкретном
  устройстве оно недоступно, проверьте на реальном телефоне — это место не проверялось на устройстве.
* Шрифт Inter (лицензия OFL, см. `assets/fonts/LICENSE.txt`).
